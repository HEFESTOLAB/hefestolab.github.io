HEFESTO Pre-BIM Modeler · In development

BIM from the first line.

HEFESTO is an evolving Pre-BIM environment for modelling, measuring and organising project information from the earliest stages. Its data core is designed to support interoperability, automation and new workflows with BIM tools and language models.

Workflow

From initial information to a usable model.

HEFESTO aims to make data available early and keep it evolving without depending on a single tool.

01 · INPUTDrawings and dataGraphical information, requirements, datasheets and project data.
02 · MODELGeometry and objects2D/3D elements with useful properties and relationships.
03 · INFORMATIONQuantities and costQuantities and cost data linked to the model.
04 · CONTINUITYInteroperabilityData prepared for other formats, tools and automation.
Component Studio

Technical components without turning every part into a separate project.

Component Studio extends HEFESTO with parametric geometry based on primitives and properties for parts and equipment.

Industrial components

The goal is to build lightweight components from dimensions and technical documentation while keeping geometry and data connected.

1Primitives and geometric operations.
2Parameters, dimensions and technical properties.
3Plates, tanks, equipment and other reusable objects.

From document to object

One development line is to make it easier for drawings and technical datasheets to become structured information and components through AI and MCP.

→Technical documentation as input.
→Data that language models can interpret.
→Human review before incorporating the result.
