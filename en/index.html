The application

Every discipline, in a single tool.

Real screenshots from the working version. Not mock-ups or marketing renders: live projects, with deadlines and clients, inside the desktop application.

ArchitectureFrom sketch to drawing

Walls, openings, joinery, slabs and roofs with a project level manager: finished floor, lintel, suspended ceiling, eaves and ridge.

StructureReal profiles, not boxes

Columns, beams and footings with a steel profile library — SHS, RHS, IPE, UPN and L — with weight per metre, steel take-off and export to analysis software.

MEP and industrialPipes, ducts and trays

Industrial networks on racks, fittings, slopes and parametric accessories, checked against the point cloud whenever a survey exists.

Everything exports in open formats
PDF · drawings and sheets DXF · 2D and 3D IFC4 · physical and analytical BC3 · FIEBDC-3 Excel · quantities Word · cost report JSON · open core
Drawings

From model to issue-ready sheet

Sheet composer with numbered sheets, A4 to A0 formats, orientation, a title block carrying project and author, and viewports dragged in from the view browser. Each viewport keeps its scale and refreshes when the model changes.

A4–A0 sheetsScaled viewports1:20 sectionsTitle blockPDF per sheet or allDXF
Detail engineering

Dimensioned, tagged details

Detail sections with real dimensions taken from the model and tags reading each element's profile: SHS, IPE, UPN, L. Annotation tools on the sheet — lines, arrows, text, frames — to finish the drawing without moving to another program.

Automatic dimensionsProfile tagsSheet annotationStructure typesSupport details

Architecture

Project elevations, not generic storeys

A level manager with the elevations actually used on site: external ground, finished floor, opening lintel, top of suspended ceiling, wall coping and geometric ridge. Every element is anchored to a base and a top constraint.

Component Studio

Parametric components with an IFC class

A solid modeller with a construction tree, boolean operations, arrays and mirroring. Every component carries its category, IFC class, material and parameters, and can become a family of types.

Construction treeBooleansParameters and typesVolume and massIfcPipeFitting
Scan2JSON

The point cloud, inside the modeller

Slice-based import with voxel reduction, cloud stacking, satellite point filtering and assisted element detection. The scan stops being an external reference and becomes part of the working environment.

Voxel reductionStacked cloudsNoise filteringElement detection
Model over scan

Checked directly against reality

The resulting model sits alongside the cloud in the same view, so deviation shows up the moment it happens. This is the workflow used to audit 134 pipes in an industrial facility and correct 44 elevation errors.

Model + cloudVisual verificationPipes and steelLevels by elevation
Quantities and cost

From model to cost data, without leaving the app

Schedules by base level, description and profile, with count, length, area and volume. Quantities link to BC3 price databases, so the cost plan comes out automatically and with real rates: export to Excel, to BC3 in the Spanish FIEBDC-3 format, and to Word reports in summary, unit-rate or breakdown form.

Schedules by levelExcelBC3 · FIEBDC-3WordSteel profiles
Modelling

Elements with type, level and parameters

Columns, beams, pipes and walls with a profile assigned by type, base and top levels, offsets and rotation. Every element keeps a stable identifier, which is what makes information traceable towards IFC and towards the cost plan.
