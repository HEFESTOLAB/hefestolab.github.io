Learning path

Six blocks. One complete system.

Start with the foundations and progress to agents, integrations and real labs. Progress is not stored: enter any block or follow the linear route.

01

Understand before you use

LLMs, tokens, context, inference, search, hallucinations and professional verification.

→ 02

Choose the right tool

Cloud and local models, privacy, cost, speed and task-based selection.

→ 03

Context is part of the system

Objectives, constraints, data, sources, formats, iteration and reusable instructions.

→ 04

From answering to acting

Agents, tools, permissions, coding agents, Skills and an Agent Ready lab with IFC Drawing.

→ 05

Connect AI to real tools

MCP, local AI, LM Studio, hardware resources, RAG and hybrid architectures.

→ 06

THE FORGE

IFC Drawing, HEFESTO, MCP, Component Studio, a DN100 flange and interoperability.
