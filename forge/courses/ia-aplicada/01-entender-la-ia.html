Entender antes de utilizar

Una base clara para tomar decisiones, formular mejores preguntas y verificar resultados.

Prioridad de revisión: mediaRevisado: 20 AGO 2026
01Entender02Modelos03Contexto04Agentes05MCP + local06The Forge

Objetivo del bloque

Al terminar, una persona sin formación previa en IA podrá explicar qué hace un modelo generativo, distinguir lo que sabe de lo que consulta, reconocer sus límites y establecer una comprobación profesional antes de usar un resultado.

  1. Inteligencia artificial generativa. Sistemas que producen contenido nuevo —texto, código, imágenes o datos— a partir de patrones aprendidos. No equivalen a una base de datos de respuestas exactas.
  2. Qué es un LLM. Un modelo de lenguaje grande estima qué fragmentos de información son coherentes a continuación. Puede razonar de forma útil, pero no posee criterio profesional ni intención propia.
  3. Tokens. El modelo procesa unidades de texto que pueden ser palabras, partes de palabras o signos. Los límites y costes suelen medirse en tokens, no en páginas.
  4. Ventana de contexto. Es el espacio de trabajo disponible para instrucciones, conversación, archivos y resultados. Más contexto no siempre significa mejor contexto: debe ser relevante y estar ordenado.
  5. Entrenamiento frente a inferencia. Durante el entrenamiento se ajusta el modelo con grandes colecciones de datos; durante la inferencia se usa el modelo ya entrenado para responder a una entrada concreta.
  6. Conocimiento interno frente a búsqueda web. Una respuesta puede proceder de patrones internos o de fuentes consultadas mediante una herramienta. Sólo la segunda opción puede aportar información externa reciente, y aun así hay que revisar la fuente.
  7. Alucinaciones. El modelo puede producir datos plausibles pero falsos, referencias inexistentes o una seguridad injustificada. La fluidez no es evidencia.
  8. Multimodalidad. Algunos sistemas trabajan con texto, imágenes, audio, vídeo o documentos. Cada modalidad añade capacidades y también posibles errores de interpretación.
  9. Herramientas. Búsqueda, cálculo, navegación, código o conectores amplían lo que el modelo puede hacer. Una herramienta ejecuta una acción; el modelo decide cómo solicitarla dentro de sus permisos.
  10. Verificación profesional. Comprobar hipótesis, unidades, fuentes, normativa, geometría y formato antes de aceptar un resultado. La responsabilidad final sigue siendo humana.

Regla operativa

Si una respuesta afecta a seguridad, cumplimiento, coste, mediciones o una decisión de proyecto, exige evidencia verificable y contrástala con la fuente competente.

Práctica final

Radiografía de una respuesta

Pide a un asistente que explique, para una persona no técnica, la diferencia entre IFC y un modelo BIM de autoría. Después:

  • separa las afirmaciones conceptuales de los datos que podrían cambiar;
  • marca qué frases necesitarían una fuente;
  • identifica cualquier término ambiguo;
  • solicita una segunda versión con supuestos, límites y fuentes claramente señalados;
  • redacta en tres líneas tu veredicto: utilizable, utilizable con correcciones o no utilizable.
