# HEFESTOLAB — landing para GitHub Pages

## Publicación rápida

1. Crea en la organización `HEFESTOLAB` un repositorio público llamado `hefestolab.github.io`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio.
3. En `Settings → Pages`, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Espera a que GitHub publique `https://hefestolab.github.io/`.

## Archivos SEO incluidos

- `index.html`: metadatos, Open Graph, Twitter Cards y JSON-LD.
- `robots.txt`: permite los robots de búsqueda y acceso de ChatGPT y Claude; bloquea por defecto los robots específicos de entrenamiento.
- `sitemap.xml`: mapa inicial del sitio.
- `llms.txt`: resumen estructurado experimental para herramientas compatibles.
- `site.webmanifest`: metadatos de aplicación web.
- `assets/images/og-hefestolab.jpg`: imagen social 1200×630.

## Antes del lanzamiento definitivo

- Sustituir enlaces `#` y el correo provisional.
- Crear páginas independientes para producto, academia, biblioteca, blog y documentación.
- Actualizar `sitemap.xml`.
- Registrar el sitio en Google Search Console y Bing Webmaster Tools.
- Validar JSON-LD con Google Rich Results Test.
- Añadir una versión inglesa y `hreflang` cuando exista.
