# HEFESTOLAB website

Sitio oficial provisional de HEFESTOLAB publicado en GitHub Pages.

- URL: https://hefestolab.github.io/
- Publicación: GitHub Actions / Static HTML
- Idioma principal: español
- Versión inglesa: /en/
- Blog: /blog/ y /en/blog/
- Tema por defecto: oscuro; el usuario puede cambiar a claro.

La publicación automática se ejecuta al hacer commit en `main`.


## Vista previa local

Esta versión utiliza rutas relativas para que la portada, el selector ES/EN y el blog mantengan estilos y navegación también al abrir los HTML con doble clic. En GitHub Pages se publican en https://hefestolab.github.io/.
